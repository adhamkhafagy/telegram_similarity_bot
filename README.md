# Design Library Bot

بوت تليجرام للبحث عن التصاميم المشابهة بالصورة، وبناء أرشيف ذكي بيكبر تلقائيًا بدون أي كود يدوي.

## طريقة الاستخدام

- ابعت صورة أي تصميم للبوت → هيرجعلك أقرب 5 تصاميم مشابهة من الأرشيف مع نسبة التشابه.
- لو التصميم جديد فعلاً ومش موجود، ابعت `/add` بعد الصورة مباشرة عشان يضاف للأرشيف بكود تلقائي.
- لو نسبة التشابه أعلى من 90%، البوت بيعتبره تكرار ويزود عداد "مرات الاستخدام" للتصميم الأصلي بدل ما يضيفه من جديد.
- `/get [الكود]` — بيرجّع صورة تصميم معين بالكود بتاعه (مثلاً `/get a1b2c3d4`).
- `/top` — بيعرض أكتر 10 تصاميم اتكررت في الأوردرات، مرتبة تنازليًا.

## التشغيل محليًا

```bash
pip install -r requirements.txt
cp .env.example .env   # وحط فيه توكن البوت بتاعك من BotFather
python bot.py
```

البوت بيقرأ ملف `.env` تلقائيًا (عن طريق `python-dotenv`)، فمفيش داعي لأي أمر `export` يدوي، لا على ويندوز ولا على Mac/Linux. الشرط الوحيد إن ملف `.env` يكون في نفس مجلد `bot.py`.

## النشر على Railway

1. اعمل push للمشروع على GitHub.
2. اربط الريبو بـ Railway وأنشئ Service جديد.
3. ضيف متغير البيئة `TELEGRAM_BOT_TOKEN` في إعدادات المشروع.
4. **مهم جدًا:** فعّل Volume في Railway واربطه بمسار `/app/chroma_data`، عشان الأرشيف يفضل محفوظ بعد أي إعادة تشغيل أو Deploy جديد. من غير Volume، الأرشيف هيتمسح كل مرة يعمل فيها Railway إعادة تشغيل للسيرفر.

## إضافة عدد كبير من التصاميم دفعة واحدة

لو عندك تصاميم قديمة على الجهاز (خصوصًا اللي اتضافت قبل تحديث `/get` ومفيهاش صورة محفوظة)، استخدمي `bulk_add.py`:

```bash
python bulk_add.py "C:\path\to\designs_folder" 123456789
```

- المسار: مجلد فيه صور بصيغة jpg/jpeg/png فقط.
- الرقم التاني: الـ Chat ID بتاعك على تليجرام. جيبيه بسهولة عن طريق إرسال أي رسالة لـ `@userinfobot` على تليجرام.

السكريبت بيبعت كل صورة لنفسك على تليجرام (عشان ياخد منها `file_id`)، وبعدين يضيفها للأرشيف بكود جديد. هيطلعلك تقرير في الآخر بكل الأكواد الجديدة وأي صور فشلت.

**ملاحظة:** التصاميم دي هتتضاف بأكواد جديدة تمامًا، حتى لو كانت مضافة قبل كده بكود قديم. الأكواد القديمة هتفضل شغالة في البحث العادي بس من غيرها صورة (`/get` مش هيشتغل معاها).

## خطوات تطوير مقترحة بعد التشغيل الأول

- إضافة أمر `/top` يعرض أكتر 10 تصاميم استخدامًا (باستخدام حقل `times_reused`).
- ربط كل تصميم برقم الأوردر بدل الاكتفاء بكود عشوائي، لو عايزة تتبع مين طلب التصميم ده قبل كده.
- توسيع البوت لاحقًا بحيث يشتغل على أكتر من صفحة/جروب في نفس الوقت مع فصل الأرشيف لكل صفحة.
